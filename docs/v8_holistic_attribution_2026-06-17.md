# V8 RL 通关卡死（won=0）全链路归因 — 2026-06-17

## 背景

当前现役模型为 live combat 路线下的新最优 `v8_livecombat_hpeff_v1/final`（ep42000），
在「省血奖励」（`V8_COMBAT_HP_EFF`）A/B 验证采纳后产出。模型表现：

- 稳定打过一幕 boss ~44%
- 卡在二幕（极少进、几乎打不过二幕 boss）
- 通关恒 0（won_game 全程 = 0）

为找通关卡死的真根因，拉了 **12 局完整对局**（seed 10000–10011，**全部死亡**）逐决策剖析。
本文落档这 12 局的全链路归因，作为后续奖励/工程迭代的依据。

---

## 根因（按严重度排序）

### 1. 【最高】牌组永远不变强

证据（12 局）：

- **11/12 局终局无任何 power / scaling 卡**：系统性跳过制胜卡（Demon Form / Limit Break / Reaper 等）。
- **25/25 营火全 REST（休息）**：0 次 SMITH（升级卡）。
- **7/12 局零升级裸组进 boss**：进 boss 战时牌组一张升级都没有。

根因：`strength_reward`（卡组实力增长奖励）已于 2026-06-01 删除（因无上限刷分，死亡局净赚 +485），
牌组评分（deck_strength）目前**只作模型输入特征、不进梯度**。结果是模型「看得见牌组强弱、却没有
任何动力去把牌组变强」——升级、删卡、选强力卡全都没有奖励信号牵引。

### 2. 【最高】战斗执行：二幕 boss 暴毙

证据：

- **二幕 boss 2/2 满血一波团灭**：是「被一套大招打死」（暴毙），不是「磨到最后一点血输」（磨不死）。
- **防御牌仅占 8–11%**：牌组防御占比过低，扛不住 boss 的爆发回合。
- 战斗奖励只有**粗粒度的 win + hp**，无法塑形到「回合级」——没有信号教模型在 boss 放大招那一回合
  提前铺防御 / 减伤。

### 3. 【前提级代码缺口】药水未接入

证据：

- **全程 `potions=[]` 恒空**：12 局一次药水都没有出现。
- **12 局 0 次用药水**。
- 状态特征 `num_potions` 恒为 0、动作空间里**没有 `use_potion` 动作**。

结论：一整类救命资源（药水）在当前管线里**完全短路**——既拿不到、状态里恒 0、也没有用它的动作。
这是代码工程层面的缺口，不是奖励问题，但直接砍掉了一条本可救命的资源线。

### 4. 【高】不打精英 → 遗物太少

证据：

- **精英接触 1.17 次/局**（健康水平应为 2–3 次/局）。
- 唯一一局摸到二幕 boss 的对局，**打了 3 个精英、攒到 9 个遗物**。
- **0 精英局恒 4 遗物**：不打精英的局遗物数恒定停在 4 个左右。

结论：模型回避精英 → 遗物获取不足 → 战力上不去 → 越往后越打不动。遗物是 STS 的核心成长线之一，
当前没有任何信号鼓励「去打精英 / 攒遗物」。

### 5. 【高】资源 / 营火使用

证据：

- **26/26 营火全 REST，0 SMITH**（与根因 1 同源，单列强调营火资源利用）。
- 删卡奖励（`V8_DECK_LEANNESS`）**已实现但默认关**。
- 遗物 / 精英获取**无定向激励**。

## 奖励设计审计结论

当前奖励**太宏观、太稀疏**：只对**结果**发钱（过层 / 过 boss / 通关），
对「**怎么变强**」（升级 / 删卡 / 选强卡 / 拿遗物 / 用药水）**零中间信号**。

### 缺口清单（7 条）

1. 牌组强度增量无奖励（deck_strength 只是输入特征，不进梯度）。
2. SMITH（营火升级）零信号 → 25/25 营火全休息。
3. 药水未接入：状态恒 0、动作空间无 `use_potion`（前提级代码缺口）。
4. 战斗黑盒无回合级信号：只有粗粒度 win + hp，无法塑形「boss 大招回合防御」。
5. 删卡奖励（`V8_DECK_LEANNESS`）已实现但默认关。
6. 精英 / 遗物无激励：回避精英 → 遗物不足。
7. node 奖励粒度过粗：过层 +3 这种结果奖励，对成长路径无导向。

## 迭代路线

**头号杠杆 = 引导牌组变强**（直击根因 1，也是最高严重度）。

### 第一个实验（进行中）

`V8_SMITH_REWARD` 营火升级卡奖励：

- 血量够时（`hp_ratio = current_hp/max_hp >= 0.5`）营火选 SMITH（升级卡）额外 **+1.0**。
- **门控、默认关**（开关 `V8_SMITH_REWARD`，关时恒返回 0.0、byte-for-byte 不影响原 reward）。
- **bounded 不可刷分**：营火数量天然有上限（每幕固定几个），累计极小，远不接近进度主线量级
  （过层 +3 / 过 boss +25 / 通关 +100）。
- 训练：从新最优续训到 **46000**，输出 `sts_models/v8_livecombat_smith_v1`。

### 后续候选

- 删卡 leanness（`V8_DECK_LEANNESS`，已实现，A/B 测开）。
- 药水接入动作空间（**代码工程**：状态 `num_potions` 接真值 + 动作空间加 `use_potion`）。
- 精英 / 遗物定向激励。
- 战斗回合级防御塑形（boss 大招回合的减伤 / 铺防御信号）。

## 方法论备注

`strength_reward` 当年因**无上限刷分**被删（死亡局净赚 +485，模型学成「多打架」而非「赢」）。
任何**重引入牌组强度信号**的尝试，必须满足三条约束：

- **bounded**（有天然上限，不可无限刷分）。
- **win-conditioned**（与赢挂钩，至少不奖励苟活 / 逃战）。
- **小权重**（远小于进度主线，不喧宾夺主）。

`V8_SMITH_REWARD` 即按此设计（营火数量天然有限 + hp 门控 + 权重 1.0）。
